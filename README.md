# SubReaper

A simple Python tool for subdomain enumeration/recon on a target domain.

## Installation

```bash
git clone https://github.com/mukidulislamzihad/subreaper.git
cd subreaper
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python3 subreaper.py example.com
```

Replace `example.com` with your target domain.

## Requirements

- Python 3
- Dependencies listed in `requirements.txt`

## Disclaimer

Use only on domains you own or have explicit permission to test.
